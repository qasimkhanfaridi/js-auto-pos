# JS Auto — In-Store POS & Inventory System

Point-of-Sale (POS) billing and inventory management system designed for **JS Auto** (Rawalpindi, Pakistan).

## 🚀 Live Demo
Access the live POS system here:
**[https://qasimkhanfaridi.github.io/js-auto-pos/](https://qasimkhanfaridi.github.io/js-auto-pos/)**

---

## ⚡ Features

- **🧾 Shop Counter Billing**:
  - Barcode scanner wedge support (instant scan-to-cart on `Enter`)
  - Real-time product search by name, brand, or SKU
  - Category filters (Oil Filters, Air Filters, AC Filters, Fuel Filters, Engine Oils, ATF, Coolants, Car Care)
  - Quick quantity adjustments (+ / -) & discount % calculator
  - Walk-in customer details

- **💰 Cash Counter & Change Calculator**:
  - One-click Pakistani Rupee cash denomination buttons (Rs. 5000, 2000, 1000, 500, 200, 100, or Exact)
  - Instant change return calculation to prevent cashier errors
  - Automatic inventory deduction upon completing sale

- **🖨️ Thermal Receipt Printing**:
  - Formatted for standard 80mm & 58mm thermal receipt printers
  - Includes shop header, bill number, itemized totals, cash/change breakdown, and return policy

- **📦 Inventory Management**:
  - Live stock status (In Stock, Low Stock alert, Out of Stock)
  - Inline stock quantity adjustment
  - Add new products with auto-generated SKUs
  - CSV export for reporting

- **🏷️ Barcode Sticker Generation**:
  - Generates Code-128 SVG barcode stickers for unbarcoded stock
  - Customizable pricing and multi-copy printing

- **📊 Daily Sales Reports**:
  - Daily revenue, transaction counts, items sold, and average ticket size
  - Transaction history log with receipt reprint capability

---

## 🛠️ Hardware Compatibility

- **Barcode Scanners**: Any standard USB / Bluetooth HID handheld scanner (Honeywell, Zebra, Netum, Eyoyo)
- **Receipt Printers**: Standard 80mm / 58mm USB/Ethernet thermal printers (Epson TM-T88, Xprinter, Rongta)
- **Label Printers**: Standard thermal barcode label printers (Xprinter XP-365B, Zebra ZD220)
